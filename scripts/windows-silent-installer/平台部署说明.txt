华力 AI 桌面助手 - Windows x64 企业静默部署包

安装方式
- 管理平台以管理员或 SYSTEM 身份直接运行 *_x64-enterprise-silent-setup.exe
- 不需要命令行参数
- 整个安装过程不显示安装向导
- 安装成功后会自动在当前 Windows 桌面会话启动应用，不会以 SYSTEM 身份启动
- 用户无需提前登录华力业务系统；应用启动后会自动显示“去登录”提示框
- 未登录时登录提示会常驻；完成登录后会自动开启一句话创建待办和站内消息提醒
- 登录后单击机器人可打开待办输入框；拖动时输入框实时跟随，点击其他桌面区域后自动隐藏
- 待办长文本会自动换行扩高，超过安全高度后框内滚动；未提交草稿在隐藏、重启或覆盖安装后仍保留
- 输入框可见且正在编辑或已有文字时，机器人不会因一分钟闲置躲藏；鼠标悬停不再切换透明精灵帧
- 仅当安装时完全没有 Windows 用户桌面会话时，系统才无法当场显示窗口
- 返回码 0 表示成功，非 0 表示失败

安装与重装规则
- 已存在之前管理员下发的整机版：先静默卸载旧版，等待卸载完成，再安装新版并自动启动
- 不存在整机版：直接安装新版并自动启动
- 旧版正在运行：卸载和安装前会自动结束旧进程，安装成功后只启动新版
- 重装不删除用户的业务登录数据和应用数据
- 如旧版卸载失败，安装包返回非 0，不会继续覆盖安装
- 如同时触发两次企业安装，后一个返回码 1618，不会与正在进行的安装相互覆盖

安装范围
- 安装类型：整台电脑（per-machine）
- 默认目录：%ProgramFiles%\华力AI桌面助手
- 开始菜单和桌面快捷方式：对该电脑的所有用户可见

平台检测规则
- 注册表路径：HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\华力AI桌面助手
- 版本字段：DisplayVersion
- 主程序：%ProgramFiles%\华力AI桌面助手\HualiAIDesktopAssistant.exe

静默卸载命令
"%ProgramFiles%\华力AI桌面助手\uninstall.exe" /S

升级说明
- 直接下发更高版本的静默包即可自动完成“卸载旧版 -> 安装新版 -> 启动新版”
- 如果应用正在运行，旧版卸载程序会先关闭旧进程

其他
- SHA256.txt 用于下发前后的文件完整性校验
- APPLICATION-SHA256.txt 是安装器内应用主程序的校验值，应与同版本个人安装包完全一致
- 安装包内含 WebView2 引导程序；如电脑未安装 WebView2，需允许其完成运行时安装
- 当前产物未使用 Windows 代码签名证书；全员下发前请由管理平台按 SHA256 加白，或使用公司证书签名
